Purpose & Audience

This is a wedding invitation website for myself and my fiancée, who is from Mexico City, where we are holding our wedding. The site acts as a digital invitation — giving guests all the info they need and letting them RSVP online. It is intended for Mexican family members and friends, primarily Spanish-speaking, who will mostly be viewing it on mobile.

Dynamic Elements

Slide-Out Navigation

initNav() toggles an open class on the nav tray when the hamburger button is clicked.

Countdown Timer

initCountdown() starts an interval calling updateDisplay() every second. A conditional checks if the wedding date has passed and swaps the timer for a celebration message if so.

Wish Wall

addWish() listens for form submission and validates that neither field is empty. Each wish is stored as an object { name, message, date } in a wishes array. renderWishes() uses forEach to build and insert wish cards into the DOM.

RequirementWhere
Multiple functionsinitNav, initCountdown, updateDisplay, addWish, renderWishes

Event listenersClick (nav), submit (wish wall)
